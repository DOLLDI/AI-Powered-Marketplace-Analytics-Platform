# Техническое задание

## Этап: сравнение цен Wildberries с Ozon и Яндекс Маркетом

## 1. Название этапа

Сравнение цен товара Wildberries с Ozon и Яндекс Маркетом.

---

## 2. Цель этапа

Реализовать модуль, который позволяет пользователю отправить товар с Wildberries и получить сравнение его цены с похожими товарами на Ozon и Яндекс Маркете.

Система должна определить исходный товар, найти похожие товары на других маркетплейсах, сравнить цены и показать пользователю, где товар выгоднее.

---

## 3. Общий сценарий работы

Пользователь отправляет ссылку на товар Wildberries или артикул товара.

Система обрабатывает запрос, получает данные исходного товара, выполняет поиск похожих товаров на Ozon и Яндекс Маркете, сравнивает цены и возвращает пользователю результат.

В результате пользователь должен получить:

— исходный товар Wildberries;
— цену на Wildberries;
— найденные товары на Ozon;
— найденные товары на Яндекс Маркете;
— цены найденных товаров;
— разницу в цене;
— процентную разницу;
— ссылки на найденные товары;
— итоговый вывод по самому выгодному варианту.

---

## 4. Обработка входных данных

Необходимо реализовать обработку пользовательского ввода.

Система должна принимать:

— ссылку на товар Wildberries;
— артикул товара Wildberries.

После получения сообщения система должна определить тип входных данных, извлечь артикул товара и передать его в дальнейшую обработку.

Если пользователь отправляет ссылку, система должна получить из неё артикул товара.

Если пользователь отправляет артикул, система должна использовать его напрямую.

---

## 5. Получение данных товара Wildberries

Необходимо реализовать получение информации об исходном товаре Wildberries.

Система должна получать следующие данные:

— артикул товара;
— название товара;
— бренд товара;
— текущую цену;
— старую цену при наличии;
— размер скидки при наличии;
— ссылку на товар;
— изображение товара при наличии;
— рейтинг при наличии;
— количество отзывов при наличии;
— категорию товара при наличии;
— основные характеристики товара при наличии.

Для дальнейшего сравнения обязательными данными являются:

— название товара;
— текущая цена;
— ссылка на товар;
— артикул товара.

---

## 6. Формирование поискового запроса

Необходимо реализовать формирование поискового запроса для Ozon и Яндекс Маркета на основе данных товара Wildberries.

При формировании запроса система должна учитывать:

— название товара;
— бренд;
— модель товара;
— важные ключевые слова;
— цифровые обозначения модели;
— буквенно-цифровые обозначения модели;
— категорию товара при наличии;
— характеристики товара при наличии.

Поисковый запрос должен быть достаточно точным, чтобы система находила именно похожий товар, а не случайные товары с частичным совпадением слов.

---

## 7. Поиск товаров на Ozon

Необходимо реализовать поиск похожих товаров на Ozon.

Система должна отправлять поисковый запрос по данным товара Wildberries и получать список найденных товаров.

По каждому найденному товару необходимо получить:

— название;
— цену;
— старую цену при наличии;
— ссылку на товар;
— изображение при наличии;
— рейтинг при наличии;
— количество отзывов при наличии;
— категорию при наличии;
— основные характеристики при наличии.

После получения результатов система должна подготовить товары Ozon к дальнейшему сравнению.

---

## 8. Поиск товаров на Яндекс Маркете

Необходимо реализовать поиск похожих товаров на Яндекс Маркете.

Система должна отправлять поисковый запрос по данным товара Wildberries и получать список найденных товаров.

По каждому найденному товару необходимо получить:

— название;
— цену;
— старую цену при наличии;
— ссылку на товар;
— изображение при наличии;
— рейтинг при наличии;
— количество отзывов при наличии;
— категорию при наличии;
— основные характеристики при наличии.

После получения результатов система должна подготовить товары Яндекс Маркета к дальнейшему сравнению.

---

## 9. Нормализация данных

Необходимо реализовать нормализацию данных перед сравнением.

Система должна приводить названия товаров, бренды, цены и характеристики к единому виду, чтобы сравнение работало стабильнее.

Нормализация должна применяться к:

— названию исходного товара Wildberries;
— названию найденных товаров Ozon;
— названию найденных товаров Яндекс Маркета;
— брендам;
— ценам;
— характеристикам при наличии.

Цены должны быть приведены к числовому формату.

Текстовые данные должны быть очищены от лишних символов, повторов и незначимых слов.

---

## 10. Сопоставление товаров

Необходимо реализовать определение степени похожести найденных товаров с исходным товаром Wildberries.

Система должна сравнивать товары по следующим параметрам:

— совпадение бренда;
— совпадение названия;
— совпадение модели;
— совпадение ключевых слов;
— совпадение цифровых обозначений;
— совпадение буквенно-цифровых обозначений;
— совпадение категории;
— совпадение характеристик при наличии;
— признаки того, что найденный товар является тем же товаром;
— признаки того, что найденный товар является похожим товаром.

Для каждого найденного товара необходимо определить уровень совпадения.

Уровень совпадения должен использоваться при сортировке и выводе результата пользователю.

---

## 11. Фильтрация найденных товаров

Необходимо реализовать фильтрацию найденных товаров.

Система должна обрабатывать результаты поиска и оставлять товары, подходящие для сравнения.

При фильтрации необходимо учитывать:

— наличие названия;
— наличие цены;
— наличие ссылки;
— степень совпадения с исходным товаром;
— соответствие бренда;
— соответствие модели;
— соответствие категории;
— соответствие характеристик при наличии.

После фильтрации в результат должны попадать наиболее релевантные товары с Ozon и Яндекс Маркета.

---

## 12. Расчёт разницы цен

Необходимо реализовать расчёт разницы между ценой Wildberries и ценами найденных товаров.

Для каждого найденного товара система должна рассчитать:

— цену товара на найденном маркетплейсе;
— разницу с ценой Wildberries в рублях;
— разницу с ценой Wildberries в процентах;
— дешевле ли найденный товар, чем товар на Wildberries;
— дороже ли найденный товар, чем товар на Wildberries;
— совпадает ли цена с ценой Wildberries.

Расчёт должен выполняться отдельно для каждого найденного товара на Ozon и Яндекс Маркете.

---

## 13. Определение самого выгодного варианта

Необходимо реализовать определение самого выгодного предложения среди Wildberries, Ozon и Яндекс Маркета.

Система должна сравнить цену исходного товара Wildberries с ценами найденных товаров на Ozon и Яндекс Маркете.

По итогам сравнения система должна определить:

— самый дешёвый вариант;
— маркетплейс, на котором найден самый дешёвый вариант;
— разницу относительно Wildberries;
— процентную выгоду относительно Wildberries;
— итоговый вывод для пользователя.

---

## 14. Сортировка результатов

Необходимо реализовать сортировку результатов перед выводом пользователю.

Система должна сортировать найденные товары с учётом:

— степени совпадения;
— цены;
— выгоды относительно Wildberries;
— качества найденного результата.

В выдаче выше должны отображаться наиболее подходящие и выгодные товары.

---

## 15. Формирование ответа пользователю

Необходимо реализовать формирование итогового сообщения для пользователя.

Ответ должен содержать:

— название исходного товара Wildberries;
— цену исходного товара Wildberries;
— ссылку на исходный товар Wildberries;
— найденные товары на Ozon;
— найденные товары на Яндекс Маркете;
— цены найденных товаров;
— ссылки на найденные товары;
— разницу в рублях;
— разницу в процентах;
— уровень совпадения найденных товаров;
— итоговый вывод по самому выгодному варианту.

Ответ должен быть понятным, компактным и удобным для чтения в Telegram.

---

## 16. Отдельный вывод по Ozon

Необходимо реализовать отдельный блок результата по Ozon.

В блоке Ozon должны отображаться:

— найденные подходящие товары;
— цена каждого товара;
— разница относительно Wildberries;
— процентная разница относительно Wildberries;
— уровень совпадения;
— ссылка на товар.

Если найдено несколько подходящих товаров, в выдаче должны отображаться лучшие варианты.

---

## 17. Отдельный вывод по Яндекс Маркету

Необходимо реализовать отдельный блок результата по Яндекс Маркету.

В блоке Яндекс Маркета должны отображаться:

— найденные подходящие товары;
— цена каждого товара;
— разница относительно Wildberries;
— процентная разница относительно Wildberries;
— уровень совпадения;
— ссылка на товар.

Если найдено несколько подходящих товаров, в выдаче должны отображаться лучшие варианты.

---

## 18. Итоговый вывод

Необходимо реализовать итоговый блок с кратким выводом.

В итоговом блоке система должна написать:

— где найден самый выгодный вариант;
— насколько он дешевле или дороже Wildberries;
— есть ли смысл рассматривать другой маркетплейс;
— насколько уверенно система сопоставила товары.

Итог должен быть сформулирован простым языком, чтобы пользователь сразу понял результат сравнения.

---

## 19. Обработка частичных результатов

Необходимо реализовать корректную обработку ситуаций, когда результат получен не полностью.

Система должна уметь сформировать ответ, если:

— найден исходный товар Wildberries;
— товары найдены только на Ozon;
— товары найдены только на Яндекс Маркете;
— на одной из площадок подходящие товары отсутствуют;
— одна из площадок временно не вернула данные;
— часть найденных товаров не содержит всех дополнительных данных.

При частичном результате пользователь всё равно должен получить доступное сравнение по тем данным, которые удалось получить.

---

## 20. Обработка ошибок

Необходимо реализовать обработку ошибок на всех этапах.

Система должна корректно обрабатывать:

— неправильный пользовательский ввод;
— невозможность извлечь артикул;
— невозможность получить товар Wildberries;
— отсутствие цены у товара Wildberries;
— отсутствие названия у товара Wildberries;
— ошибки поиска на Ozon;
— ошибки поиска на Яндекс Маркете;
— отсутствие подходящих товаров;
— ошибки получения цены;
— ошибки формирования результата;
— внутренние ошибки сервиса.

Пользователь должен получать понятное сообщение о ситуации, а система должна сохранять техническую информацию для дальнейшего анализа.

---

## 21. Сохранение истории запросов

Необходимо реализовать сохранение истории пользовательских запросов.

Для каждого запроса нужно сохранять:

— ID пользователя;
— отправленную ссылку или артикул;
— артикул Wildberries;
— название товара Wildberries;
— цену Wildberries;
— сформированный поисковый запрос;
— найденные товары Ozon;
— найденные товары Яндекс Маркета;
— рассчитанную разницу цен;
— итоговый самый выгодный вариант;
— статус обработки;
— дату и время запроса.

История нужна для анализа работы модуля, отладки и дальнейшего расширения проекта.

---

## 22. Кэширование результатов

Необходимо реализовать кэширование данных.

Кэширование должно применяться к:

— данным товара Wildberries;
— результатам поиска на Ozon;
— результатам поиска на Яндекс Маркете;
— итоговому результату сравнения.

Кэширование нужно для ускорения повторных запросов и снижения количества обращений к маркетплейсам.

При повторной проверке одного и того же товара система должна использовать актуальный сохранённый результат, если он ещё подходит для выдачи.

---

## 23. Логирование

Необходимо реализовать логирование работы модуля.

В логах должны фиксироваться:

— начало обработки запроса;
— пользовательский ввод;
— извлечённый артикул;
— успешное получение товара Wildberries;
— ошибки получения товара Wildberries;
— поисковый запрос;
— результаты поиска Ozon;
— результаты поиска Яндекс Маркета;
— ошибки поиска по маркетплейсам;
— количество найденных товаров;
— количество отфильтрованных товаров;
— итоговый результат сравнения;
— время обработки запроса;
— технические ошибки.

Логи должны позволять быстро понять, на каком этапе возникла проблема.

---

## 24. Административная информация

Необходимо реализовать сохранение базовой статистики по этапу.

Система должна учитывать:

— количество запросов на сравнение;
— количество успешных сравнений;
— количество частично успешных сравнений;
— количество ошибок;
— количество запросов по каждому пользователю;
— самые часто проверяемые товары;
— среднее время обработки запроса;
— частоту успешного поиска на Ozon;
— частоту успешного поиска на Яндекс Маркете.

Эти данные нужны для контроля качества работы модуля.

---

## 25. Требования к скорости работы

Модуль должен обрабатывать запрос за разумное время для Telegram-бота.

Пользователь должен получать промежуточное сообщение после отправки товара.

После завершения обработки пользователь должен получить итоговый результат сравнения.

При долгой обработке система должна сохранять понятное состояние для пользователя.

---

## 26. Требования к качеству результата

Результат сравнения должен быть полезным для пользователя.

Система должна стремиться показывать товары, которые действительно похожи на исходный товар Wildberries.

При сравнении должны учитываться не только цены, но и похожесть найденных товаров.

В выдаче должны отображаться наиболее релевантные варианты.

Итоговый вывод должен помогать пользователю быстро понять, где товар выгоднее.

---

## 27. Требования к стабильности

Модуль должен продолжать работу при частичных сбоях внешних источников.

Если данные получены только с одной площадки, система должна сформировать результат на основе доступных данных.

Если найденный товар содержит неполные дополнительные данные, но содержит название, цену и ссылку, система должна использовать его для сравнения.

Если часть данных отсутствует, итоговое сообщение должно оставаться корректным и понятным.

---

## 28. Финальный результат этапа

По итогам этапа должен быть реализован рабочий модуль, который:

— принимает ссылку или артикул Wildberries;
— получает данные товара Wildberries;
— ищет похожие товары на Ozon;
— ищет похожие товары на Яндекс Маркете;
— сравнивает цены;
— рассчитывает разницу в рублях;
— рассчитывает разницу в процентах;
— определяет самый выгодный вариант;
— показывает ссылки на найденные товары;
— формирует понятный ответ пользователю;
— сохраняет историю запросов;
— кэширует результаты;
— логирует работу модуля;
— корректно обрабатывает ошибки и частичные результаты.

---

## 29. Критерии готовности этапа

Этап считается готовым, если пользователь может отправить товар Wildberries и получить сравнение цены с Ozon и Яндекс Маркетом.

Готовый результат должен включать:

— корректную обработку ссылки Wildberries;
— корректную обработку артикула Wildberries;
— получение данных исходного товара;
— поиск похожих товаров на Ozon;
— поиск похожих товаров на Яндекс Маркете;
— фильтрацию найденных товаров;
— расчёт разницы цен;
— определение самого выгодного варианта;
— вывод результата в Telegram;
— сохранение запроса и результата;
— обработку ошибок;
— логирование основных действий системы.
